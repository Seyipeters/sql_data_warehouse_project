# LinkedIn Project Description (Entry Level)

## SQL Data Warehouse Project | SQL Server, Medallion Architecture, Star Schema

Built a complete entry-level data warehouse project using SQL Server with Bronze, Silver, and Gold layers, including reusable load procedures, sample source data, and validation queries.

### Highlights
- Implemented medallion architecture (Bronze, Silver, Gold) with clear layer responsibilities.
- Built and fixed ingestion procedures for CRM and ERP source data.
- Added Silver data-cleaning transforms and Gold dimensional models.
- Designed star schema tables (`dim_customers`, `dim_products`, `fact_sales`) for analytics.
- Added one-command pipeline run script and validation queries.
- Rewrote project documentation to match real runnable workflow.
